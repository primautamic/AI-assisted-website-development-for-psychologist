# Bright Minds Clinic

Please create a website for a clinical psychologist, serving children and adolescents, specialised in neurodivergence assessments and intervention, like autism, ADHD, dyslexia, dyscalculia, etc. The clinic is running on site and mobile in radius 100 km from the clinic location in Melbourne CBD area, Victoria. This website should be containing button for booking, contact us (email & phone). there should be a dedicated page for pricing, make it detail and transparent. use cute but professional, not too colourful/contrast, use combination such as deep blue/green with light ivory/cream, use simple, a bit cute and unique and bold font for the big header, and use simple standard font for the page/body. if you need any other information, please ask me.
